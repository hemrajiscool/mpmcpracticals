# Microprocessors & Microcontrollers Lab (ET307N)

Clean, copy-paste **8085 & 8051 Assembly** code (comment-free), **Proteus** circuit diagrams, concise PDF-style write-ups, and step-by-step **Keil uVision / Proteus / GNUSim8085** operation guides for all 10 lab practicals.

Each practical file follows the same layout:
1. **Copyable Code** at the top (no comments, verified for Keil / GNUSim8085)
2. **Circuit Diagram / Pinout**
3. **Clean Write-Up** (Aim, Apparatus, 10–30 word Theory, Steps, Conclusion)
4. **Software Operation Guide** (exact Keil setup, Proteus search sections & component keywords, and `.hex` linking steps)
